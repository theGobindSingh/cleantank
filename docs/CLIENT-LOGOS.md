# Client logos still needed

The clients strip shows only clients with a logo. These clients from INFO-BANK §7 are in Payload, cleared and listed by name on the about page, but have no logo yet, so the strip leaves them out. This doesn't block launch.

A logo can be any SVG, PNG, JPEG or WebP image. Under Clients in the admin, either paste the image's address into the client's Logo link, or upload the file as the Uploaded logo. The site copies a linked logo into Media on save and again on every deploy, so visitors never load it from the client's server; if the copy fails, the reason shows under the link. A copy from a link wins over an uploaded file. A vector logo (SVG) stays sharp at any size, so prefer it when the client has one. When a logo is in, remove the name from this list.
